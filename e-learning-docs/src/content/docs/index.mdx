## 📐 ข้อมูลอ้างอิงและสูตรการคำนวณ (Reference)

<CardGrid>
  <Card title="สูตรการคำนวณในระบบ (Calculation Formulas)" icon="setting">
    รวบรวม 5 สูตรและเกณฑ์การประเมินสำคัญในระบบ ได้แก่:
    - **Quiz Scoring:** การคิดคะแนนร้อยละและเกณฑ์ผ่าน/ไม่ผ่าน
    - **Course Progress:** เปอร์เซ็นต์ความคืบหน้าและการออกใบประกาศ
    - **Gamification:** การสะสมดาวและจำนวนวันเข้าเรียนต่อเนื่อง (Streak)
    - **Teacher KPIs:** อัตราการเรียนจบ และการคัดกรองกลุ่มที่ต้องดูแลพิเศษ
    - **Donut Chart SVG:** การคำนวณ Offset กราฟวงกลมแสดงผลลัพธ์
